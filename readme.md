# Management Innovation Club (MIC)

Official website for the Management Innovation Club based at ESSG Annaba, Algeria.

## Features
- **Modern Responsive Design**: Built with HTML5, CSS3, and React.
- **Bilingual Interface**: Full support for both French and English.
- **Events Showcase**: Stagera, HackMinds, MindWaves, ACF, InnoStation, and StartEast.
- **Registration Form**: Validated intake form connected to Cloud Firestore and Google Sheets webhook.
- **Vercel Ready**: Preconfigured for instantaneous Vercel deployment (`vercel.json`).
